KNN changes 1 / 3 / 5 (2026-10-04)

Scope
- Only the event-parallel backend changes. train.py still defaults to legacy.
- 1: build batch-local launch metadata from CPU Batch.ptr before data.to(device),
  transfer once, and share across GravNet layers. The planned CUDA operator has
  no device-to-host copies or explicit stream synchronization.
- 3: one task per needed event/query block; omit rectangular-grid padding blocks.
  --knn-block-size accepts 128, 256, 512 or 1024; default is now 128,
  based on the TITAN RTX measurements. Compare on other training GPUs as needed.
- 5: allocate outputs with empty; set_defaults still initializes EVERY element,
  including missing-neighbor sentinels and distances. Remove only duplicate zeros.
- Candidate traversal, distance arithmetic, replacement/tie handling, edge order,
  differentiable edge-distance recomputation, and mean/max aggregation are retained.
- No new model parameters/buffers or checkpoint format changes.
- Plans support eager single-device/DDP. DataParallel cannot split event metadata
  like ordinary node tensors and is explicitly rejected for this backend.
- Callers without CPU ptr still work: model forward prepares a plan once via a
  CPU copy of batch. For full benefit, pass a plan made before moving data to GPU.
- GPU plans must be consumed on their upload stream, or after a CUDA stream wait.

Benchmark interpretation
The 1024 variants below intentionally retain the historical comparison settings;
they are not the current training default (128).
- baseline: original event-parallel scheduling, GPU counts, CPU row-split readback,
  and zero allocation. This is NOT the older serial-event legacy implementation.
- 1_only: precomputed metadata, rectangular grid, zero allocation, block=1024.
- 1_3: add packed tasks, retain zero allocation and block=1024.
- 1_5: metadata plus single initialization, rectangular grid.
- 1_3_5: packed tasks and single initialization; also sweep other block sizes.
- Fail before timing if any index, distance-bit or edge-order comparison fails.
- Warm up, randomize variant order, save every sample and median wall time.
- search_only and graph exclude plan preparation. The inclusive graph measurement
  includes CPU preparation/H2D once per batch and KNN calls for all recorded layers.
- These are KNN measurements, not full training-step or epoch speedups; model
  feature aggregation, dense layers, loss, backward, data loading and DDP are excluded.
- --describe-only works without a GPU and reports block counts, NOT timings.
